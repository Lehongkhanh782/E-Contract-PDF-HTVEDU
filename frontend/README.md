# Giao diện nhập liệu

Website tiếng Việt cho nhân sự tạo bộ hợp đồng. React + TypeScript + Vite.

Hướng dẫn chạy nằm ở `README.md` của repo gốc.

| File | Nội dung |
| --- | --- |
| `src/App.tsx` | Màn hình chính: 6 bước từ chọn cơ sở đến tải PDF |
| `src/components.tsx` | Các ô nhập dùng lại: Field, Select, TextArea, Section |
| `src/api.ts` | Gọi backend và dịch lỗi sang tiếng Việt |
| `src/defaults.ts` | Giá trị khởi tạo, hồ sơ mẫu và định dạng tiền |
| `src/types.ts` | Kiểu dữ liệu khớp với schema của backend |
| `src/App.css` | Trình bày, có bố cục riêng cho màn hình hẹp |
